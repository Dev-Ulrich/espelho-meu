# Espelho Meu

Projeto da turma 1TDSPW de ADS da FIAP para a Global Solution 2026/2 — CitizenTech.

O Espelho Meu usa uma foto e um questionário para sugerir opções de cabelo e maquiagem, explicar as recomendações e simular os resultados.

## Como contribuir

A equipe trabalha na branch compartilhada `main`. Antes de editar, sincronize com `git pull --ff-only origin main`. Faça commits com a sua própria conta GitHub e rode `git pull --rebase origin main` antes de `git push origin main`. Se surgir um conflito, resolva com quem alterou o mesmo arquivo.

Mantenha o código e as instruções de execução na pasta da disciplina. Guarde credenciais, fotos pessoais e arquivos de identificação com RM fora do repositório público.
